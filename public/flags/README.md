# Flag images

PNG renders (330 px wide) of flags from [Wikimedia Commons](https://commons.wikimedia.org/),
downloaded by `npm run data:flags` from the list in `content/flags.yaml`. Do not edit by hand.

`credits.json` records, for each image, its Commons file name, licence and author. Most flag
images are in the public domain; any other licence is shown next to the flag in the app.
