# Les banderes

PNG de 330 px d'amplada que renderitza [Wikimedia Commons](https://commons.wikimedia.org/) a
partir dels SVG originals. Les baixa `npm run data:flags` segons la llista de `content/flags.yaml`;
no es toquen a mà.

`credits.json` apunta, per a cada imatge, el fitxer de Commons, la llicència i l'autor. Quasi totes
són de domini públic; les que no, l'app en cita l'autor sota la bandera.
