# Lots de feina

L'índex dels lots oberts i tancats. Com es treballa, a [TREBALL.md](../TREBALL.md). Cada lot nou,
a partir de [la plantilla](lots/_plantilla.md).

Estats: **obert** (ningú no hi treballa), **en marxa** (una sessió hi és), **integrar** (la recerca
és feta, falta passar-la al codi), **tancat**.
